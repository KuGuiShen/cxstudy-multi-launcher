# 学习通桌面多开器（非官方）

一个面向 Windows 的学习通（cxstudy）桌面端多实例启动与账号管理工具。

本项目为第三方工具，与超星、学习通官方无任何关联。

## 简介

学习通 Windows 客户端基于 Electron。本工具通过为每个实例指定独立的
`--user-data-dir` 数据目录，让多个实例的登录状态和本地数据互不影响，
从而在一台电脑上同时管理多个账号。

本工具只负责启动和管理独立实例，不修改学习通客户端，也不包含任何登录
破解、代刷或绕过服务器限制的功能。

## 功能特点

- 每个账号使用独立数据目录，登录状态互不干扰
- 图形化账号管理：新建、重命名、备注、删除账号
- 按需创建多个独立实例，数量不受工具本身限制
- “临时多开”模式，适合临时登录或一次性窗口
- 一键停止选中实例、停止全部多开实例
- 清空指定账号数据，重新扫码或登录
- 自动检测实例运行状态
- 支持修改学习通程序路径与实例数据目录
- 无第三方 Python 依赖，仅使用 Python 标准库和 tkinter

## 平台支持

| 平台 | 支持情况 | 说明 |
| --- | --- | --- |
| Windows 10/11 | 支持 | 使用独立 `--user-data-dir` 启动桌面客户端 |
| Android / 安卓平板 | 不使用本工具 | 可尝试系统自带的应用分身/双开 |
| iPhone / iPad | 不支持 | iOS/iPadOS 不允许同一应用创建多个独立实例 |

Android 可尝试系统自带的应用分身/双开；iOS/iPadOS 没有同等的多实例
机制，可改用网页版或轮流登录。服务端是否允许同一账号多设备同时在线，
仍取决于学习通平台规则。

## 环境要求

- Windows 10 或 Windows 11
- Python 3.8 及以上版本（需要包含 tkinter）
- 已安装学习通 Windows 客户端

程序默认使用以下路径，也可以在界面中修改：

```text
学习通程序：D:\cxstudy\cxstudy.exe
实例数据目录：D:\cxstudy\profiles
```

## 快速开始

1. 安装 Python，并在安装时保留 `tkinter` 组件。
2. 下载或克隆本仓库。
3. 双击 `学习通多开器.pyw`。
4. 点击“新建账号”，填写一个容易辨认的名称。
5. 选中账号并点击“启动选中”。
6. 在新的学习通窗口中完成扫码或账号登录。
7. 重复以上步骤即可添加更多独立账号实例。

如果双击 `.pyw` 文件没有反应，可以右键选择“打开方式”并使用 Python
打开，或者在当前目录执行：

```powershell
pythonw .\学习通多开器.pyw
```

## 使用方式

### 启动已保存账号

选中账号，点击“启动选中”。首次启动需要在学习通窗口内登录，之后的登录
状态会保存在该账号对应的数据目录中。

### 临时多开

点击“临时多开”，每点击一次就会创建一个全新的临时数据目录和一个独立
实例。临时实例不会被加入已保存账号列表，也不共享之前账号的登录状态。

### 停止实例

- “停止选中”：停止当前选中的账号实例。
- “停止全部多开实例”：停止由本工具管理的全部实例，不影响正常启动的
  默认学习通客户端。

### 重新登录

选中账号后点击“清空数据重登”。该操作会清除对应数据目录中的登录状态，
下次启动时需要重新登录。

## 工作原理

每个账号实例通过独立参数启动：

```text
cxstudy.exe --user-data-dir=<账号独立数据目录>
```

Electron 会把该实例的本地存储、登录凭据、缓存和账号配置写入指定的数据
目录。因此，不同目录中的实例可以同时运行，且不会共享登录状态。

工具不会修改 `cxstudy.exe`、`app.asar` 或其他客户端文件。

## 目录结构

```text
学习通多开器/
├─ 学习通多开器.pyw   # 图形界面主程序
├─ 使用说明.txt       # 详细使用说明
├─ README.md         # 项目说明
└─ .gitignore        # Git 忽略规则
```

运行后会自动生成：

```text
config.json          # 本地账号列表与程序设置（不会上传到 Git）
profiles/            # 各账号的独立实例数据（不会上传到 Git）
```

## 数据与隐私

- 账号数据保存在本机 `profiles` 目录中，请勿将整个目录发送给他人。
- `config.json` 可能包含账号备注和本机路径，本项目已默认忽略该文件。
- 请勿在 Issues、截图或日志中暴露登录令牌、二维码、手机号等敏感信息。
- 删除账号或清空数据后无法恢复，操作前请确认。

## 常见问题

### 双击程序没有反应

请确认电脑已安装 Python，并尝试右键使用 Python 或 `pythonw` 打开。

### 提示找不到学习通

点击界面中的“浏览…”，重新选择学习通安装目录下的 `cxstudy.exe`。

### 状态一直没有刷新

部分安全软件会限制读取其他进程信息。可以尝试关闭相关限制，或以管理员
身份重新运行本工具。

### 同一账号能否同时在多个设备登录

本工具只能解决本机多个客户端实例的问题。同一账号能否同时在多个设备
或窗口中在线，由学习通服务器规则决定。
